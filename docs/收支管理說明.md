# 三泰通收支管理

## 入口

電腦左側「10 收支管理」；手機下方「更多」→「收支管理」。
營運總覽顯示本月營運損益，可點選前往收支管理。

## 新增

選擇「新增收支」，填入實際收付款日期、類型、分類、金額、幣別及收付款帳戶。
分類可選建議文字，也可自行輸入。對象、用途／備註為選填。
CNY 須填「1 CNY 等於多少 AUD」，該筆換算匯率會保存；AUD 固定為 1。

- 營運支出：薪資、租金、水電、運費、耗材等。
- 其他收入：利息、非商品銷售的服務收入等。
- 資金轉入：老闆投入、借入款等，不計入利潤。
- 資金轉出：提領、償還借款本金等，不計入利潤。借款利息則登記營運支出。

客戶貨款仍在「客戶帳款」登記，不重複列其他收入。
商品進貨成本仍由批次與出貨鎖定成本計算，不重複列營運支出。
已納入商品成本的運費等也不要重複登錄。

## 月度數字

營運損益 = 當月已出貨毛利 + 當月其他收入 - 當月營運費用。
出貨毛利按填寫的出貨日期，收支按填寫的收付款日期。
出貨缺少匯率或鎖定成本時顯示「—」，不當成零計算。
上方總覽為整月有效紀錄合計，不受下方類型／分類篩選影響。
這是營運管理用損益，沒有未付款費用、稅務調整或完整銀行餘額。
收付款帳戶目前是紀錄欄位，不會自動算銀行或現金結餘。

## 修正與作廢

編輯須填原因，異動紀錄保留修改前後內容、操作人與時間。
作廢也須填原因，作廢後不再計入合計；原紀錄仍保留，可選「含作廢紀錄」查看。
作廢紀錄不可再編輯。若需重建，請新增正確紀錄並在備註說明。

## 權限

管理員與主管具有完整收支權限。
一般員工（含財務）預設沒有收支權限，管理員可在「收支管理」最下方逐人分配：
無權限／僅查看／查看、新增、修改及作廢。
收支查看權限包含薪資、資金往來和月度損益，分配前請確認對象。
員工收到授權後重新整理頁面即可看到入口。已停用帳號無法存取。
