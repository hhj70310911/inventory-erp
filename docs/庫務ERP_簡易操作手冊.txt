庫務 ERP 簡易操作手冊
員工與管理員使用版｜2026 年 9 月 23 日

正式網站：https://inventory-erp-sigma.vercel.app/
本手冊依目前系統功能編寫，可使用 Windows 記事本開啟。

==================================================
快速開始：每天照這個順序操作
==================================================

第一次設定：
07 基礎資料 → 建立倉庫、供應商、客戶、員工
02 商品與庫存 → 建立商品 SKU

日常作業：
貨到了 → 03 採購入庫
接到訂單 → 05 銷售與出貨 → 建立銷售單
實際交貨 → 05 銷售與出貨 → 從倉庫出貨
收到款項 → 06 客戶帳款 → 登錄收款
查庫存 → 02 商品與庫存
查每批貨的成本與利潤 → 04 批次帳務
改密碼 → 09 帳號管理

最重要的四件事：
1. 建立銷售單不會扣庫存；確認出貨才扣庫存並鎖定成本。
2. 出貨不等於收款，收到錢之後還要另外登錄收款。
3. 調整剩餘庫存成本，不會改動以前已出貨的成本及毛利。
4. 每人使用自己的帳號，系統才能記錄實際操作人。

練習請使用管理員提供、已確認與正式資料隔離的測試網站。
正式網站會記錄真實帳務，不要在正式網站建立練習訂單。
若尚未取得測試網址，先詢問管理員。測試資料不會隨程式更新
自動搬到正式網站。

==================================================
一、登入與基本操作
==================================================

1. 開啟網站，輸入自己的 Email 及密碼，按「登入」。
2. 登入後使用選單切換功能。
3. 點選單據或批次標題，可展開明細。
4. 送出資料後，確認成功訊息並核對下方紀錄。
5. 資料未更新時，可按右上角「重新整理」。
6. 離開共用電腦前，按「登出帳號」。

帳號或密碼錯誤時，會留在登入頁顯示錯誤訊息。
看不到部分功能或按鈕，可能是權限不同，請詢問管理員。
手機上可左右滑動選單；明細表太寬時，可在表格內左右滑動。

若送出後網路中斷，不確定是否成功：
先重新整理並查紀錄，確認沒有成功建立，再重新輸入。
不要反覆新增同一筆入庫、訂單或收款。

==================================================
二、建立倉庫、供應商、客戶與商品
==================================================

【倉庫、供應商與客戶】
位置：07 基礎資料

1. 找到對應區塊，填寫編碼及名稱。
   例如：倉庫編碼 WH-N，名稱「北倉」。
2. 客戶及供應商可以加備註，供老闆或同事自行記錄。
3. 按對應的新增按鈕。

同一個對象只需建立一次，以後從選單選取即可。
新增前先看既有清單，避免建立重複客戶或供應商。

【商品 SKU】
位置：02 商品與庫存 → 新增商品 SKU

1. 填 SKU 編碼，例如 IGET-ONE-MINT。
2. 填商品名稱／規格，例如 IGET ONE 薄荷。
3. 商品系列可填 IGET ONE，方便彙總同系列商品。
4. 填庫存單位，例如「支」。
5. 填參考售價（AUD，可填 0）。
6. 按「建立商品」。

SKU 是一個獨立管理庫存的商品規格。
不同口味或規格若要分開計數，請分別建立 SKU。
同一 SKU 不同時間進貨，沿用原 SKU，由系統建立不同批次。
同一商品單位要一致，不要一下用「盒」、一下用「支」。
參考售價不會鎖定成交價格；每張銷售單都要填這次實際單價。

【商品編輯、刪除與停用：管理員／主管】
位置：02 商品與庫存 → 商品目錄

「編輯」：修改商品名稱、系列、庫存單位及參考售價，按「儲存商品」。
SKU 編碼不變；系列留空即可移出該系列。參考售價不改舊訂單售價。
單位只更正文字，不換算數量，例如「5000支」改「支」，庫存數字不變。

「刪除」：只可刪除從未有進貨、訂單等紀錄的誤建商品。
即使相關單據已沖銷，歷史仍存在，不能直接刪除。
刪除前會要求確認，商品資料無法復原，操作紀錄仍保留。

「停用」：必須各倉庫沒有剩餘庫存，也沒有待出貨訂單。
停用後不再出現在新進貨／銷售選單及使用中庫存彙總，舊帳務保留。
可以把「顯示商品」切為「已停用」，找到商品並按「重新啟用」。
若需沖銷已停用商品的出貨，先重新啟用，再處理回庫。
不能刪除或停用的原因會顯示在商品旁，請依原因處理。

以上商品管理功能目前先提供測試版驗收，正式站須待確認後更新。

==================================================
三、貨到了：採購入庫
==================================================

位置：03 採購入庫

1. 選交易幣別：AUD 澳幣或 CNY 人民幣。
2. 確認入庫日期，填備註（選填）。
3. 可填批次名稱／供應商批號，例如「9 月 A 批」。
4. 選供應商與這批貨實際進入的倉庫。
5. 選商品 SKU，填數量及每一單位的進貨成本。
6. 多項商品可按「＋ 新增明細」。
7. 核對後按「確認採購並入庫」。
8. 查看入庫紀錄，再到「02 商品與庫存」確認數量。

每個明細會產生獨立系統批號，並增加所選倉庫的庫存。
一張入庫單只選一個倉庫；貨物分送不同倉庫，請按各倉實收
數量分別登錄，不要在兩個倉庫各填一次整批總數。

成本填「單位成本」，不是整批總額。
例如 30 支、每支 AUD 40：數量填 30，成本填 40，總成本 1,200。
如需包含運費等費用，請先依公司方式分攤至每支，再填入。

人民幣匯率是「1 CNY 等於多少 AUD」。
例如填 0.20，代表 CNY 100 換算 AUD 20，這只是計算示例。
請填公司確認的匯率；系統不會自動查詢即時匯率。

==================================================
四、查貨在哪個倉庫、還剩多少
==================================================

位置：02 商品與庫存

「各倉庫與總庫存」：
查看每個 SKU 在各倉的數量，以及所有倉庫加總。

「商品系列總庫存」：
按系列及相同單位彙總，不會混加不同單位。

「倉庫批次庫存」：
查看商品、倉庫、批次、數量及入庫日期。
有財務權限者可看目前成本，可用商品、倉庫或批次關鍵字搜尋。

入庫自動增加、出貨自動扣除，不用手動修改總庫存。
即使所有倉庫合計足夠，所選出貨倉庫不足時，仍不能出貨。
系統不會自動向其他倉庫借貨。

目前沒有獨立的倉庫調撥或盤點調整畫面。
搬倉或實物數量不符時，先交主管確認，不要用假採購或假銷售補數量。

==================================================
五、接單：建立銷售單
==================================================

位置：05 銷售與出貨 → 建立銷售單

1. 選幣別，確認銷售日期與備註。
2. 選客戶。
3. 選商品，填訂購數量與這次實際成交單價。
4. 多項商品可新增明細。
5. 核對後按「建立銷售單」。

同一客戶這次賣 50、下次賣 60，可以分別輸入。
售價是客戶要付多少；成本是公司的貨物成本，兩者不要填反。

建立訂單後會產生應收金額，但尚未扣庫存、尚未鎖定出貨成本。
可以先收訂金，再分次出貨。

==================================================
六、交貨：確認出庫
==================================================

位置：05 銷售與出貨 → 從倉庫出貨

1. 確認出貨日期及備註。
2. 選訂單及本次實際出貨倉庫。
3. 填各商品本次出貨量，本次不出的商品填 0。
4. 按「確認 FIFO 出庫」。
5. 展開下方銷售訂單，核對出貨紀錄與批次。

FIFO 是「先進先出」：系統在所選倉庫內，優先扣該商品較早
入庫的批次。一筆出貨可能扣到多批，各批數量及成本分別記錄。
目前由系統自動分配，沒有手動指定出貨批次的選單。

一張訂單可以分次出貨，也可以分別從不同倉庫出貨。
每次只填這次實際交貨量，不能超過訂單尚未出貨量。

確認出貨後，系統會扣庫存，並記錄：
日期、操作人、倉庫、客戶、商品、批次、數量及當時成本。
此時成本鎖定，之後調價不會重算這筆出貨的成本或毛利。

==================================================
七、收錢：登錄收款與查欠款
==================================================

位置：06 客戶帳款 → 登錄收款

1. 確認收款日期，可在備註記錄現金、轉帳等說明。
2. 選對應訂單。
3. 填本次實際收到的金額。
4. 按「確認收款」。
5. 核對「客戶欠款」及「訂單收款明細」。

可以分次收款，金額必須大於 0，且不可超過該訂單未收金額。
使用訂單的幣別，不要直接把人民幣數字填進澳幣訂單。

例如訂單 AUD 1,000，今天收到 600：
本次填 600，系統顯示已收 600、未收 400。
下次收到尾款再登錄 400，不要再填整張訂單 1,000。

「客戶未收款」包含尚未出貨訂單；「批次帳務」只計已出貨
部分，兩邊金額不一定相同。先收款但尚未分配到出貨的部分，
會顯示為「未分配至出貨批次」。
收款會依出貨先後分配到批次。
欠款按幣別分列，AUD 與 CNY 的原幣金額不要直接相加。

==================================================
八、查每批貨的成本、收款與利潤
==================================================

位置：04 批次帳務 → 搜尋並展開批次

可以查看：
－供應商、商品、入庫日期、系統批號及入庫倉庫。
－原始進貨單價、進貨總成本。
－目前庫存成本、各倉剩餘量、總出貨量。
－出給誰、從哪裡出、由誰操作、售價是多少。
－出貨鎖定成本、應收、實收、未收與毛利。

三種成本：
1. 原始進貨成本：當初入庫的價格，保留不變。
2. 目前庫存成本：剩餘商品目前採用的價格。
3. 出貨鎖定成本：確認該次出貨時的價格，不隨後續調價改變。

已出貨毛利 = 已出貨銷售額 − 已出貨鎖定成本。
毛利不等於已收現金，也尚未扣除其他營運費用。
批次金額彙總以 AUD 顯示；明細請看清楚各欄幣別。
若金額顯示「—」，可能缺少換算資料，不代表是 0，請交主管確認。

【調整剩餘成本：管理員／主管】

1. 展開批次，確認商品、倉庫與剩餘數量。
2. 找到「調整剩餘庫存成本」。
3. 填新的單位成本及調整原因。
4. 按「確認調整剩餘成本」。
5. 核對目前成本及下方「成本調整歷史」。

調整立即套用該批所有倉庫的剩餘庫存，不改變數量。
已出貨成本、毛利及已收款不會被重算。
已建立但未出貨的訂單，在真正出貨時才採用當時成本。
沿用該批原幣別與入庫匯率，不能指定回溯生效日期。
無剩餘庫存的批次不能調整，每次調整均保留人員、時間及原因。
若提示成本已被更新，請重新整理、核對最新價格後再操作。

==================================================
九、填錯資料怎麼辦
==================================================

已確認的入庫、出貨、收款，用「沖銷」撤回該筆作業效果，
保留原單據與原因，不會刪除歷史。請交管理員／主管核對操作。

【入庫錯誤】
03 採購入庫 → 展開入庫紀錄 → 沖銷入庫。
已有後續庫存異動或成本調整歷史的批次，不能直接沖銷入庫。

【出貨錯誤】
05 銷售與出貨 → 展開訂單及出貨紀錄 → 沖銷出貨並回庫。
數量回到原倉庫，訂單恢復待出貨量。
若批次已調價，回庫商品採該批目前成本；重出時記錄新的成本。
沖銷出貨不等於取消訂單，也不會自動退款。

【收款錯誤】
06 客戶帳款 → 訂單收款明細 → 沖銷收款。
撤回該筆已收金額，訂單未收金額相應增加。
系統紀錄沖銷不會替你執行銀行退款。

【成本調整填錯】
若還有剩餘庫存，可再次調整並說明原因，兩次歷史都會保留。
期間若已出貨，該次出貨成本不會自動改回。

【銷售單的客戶、數量或售價填錯】
目前沒有直接修改或取消整張銷售單的畫面。
先停止後續出貨，聯絡管理員處理，不要直接重開一張而留下重複應收。

==================================================
十、員工帳號與密碼
==================================================

【建立帳號：管理員／主管】
位置：07 基礎資料 → 員工與權限

1. 填員工 Email、姓名及至少 8 碼的初始密碼。
2. 選權限，按「建立員工」。
3. 將登入資料私下交給本人，請本人登入後修改密碼。

主要分工：
倉管：查庫存、出貨，不顯示成本及帳款金額。
業務：建立客戶、銷售單，不顯示成本及帳款金額。
財務：查看財務資料、登錄收款。
主管：管理 ERP 作業、基礎資料、員工及成本調整。
系統管理員：另可重設其他啟用中的員工密碼。

主管不等同系統管理員，不能使用管理員重設密碼功能。
員工不再使用時，可在清單按「停用」，保留既有操作紀錄。

【修改自己的密碼：所有使用者】
位置：09 帳號管理 → 修改自己的密碼

1. 輸入目前密碼。
2. 輸入至少 8 碼的新密碼，再輸入一次確認。
3. 按「儲存新密碼」。
4. 返回登入頁後，使用新密碼登入。

新密碼不可與原密碼相同。修改後，原有登入狀態會失效。

【員工忘記密碼：系統管理員】
位置：09 帳號管理 → 管理員重設員工密碼

1. 選員工。
2. 輸入管理員自己目前的密碼，不是員工舊密碼。
3. 填員工的新密碼及確認密碼。
4. 按「重設員工密碼」，將新密碼私下交給本人。

員工原登入狀態會失效。系統不提供查看原密碼。
此功能不能重設其他系統管理員；管理員忘記自己的密碼時，
請聯絡系統維護人員。

==================================================
十一、查操作紀錄與每日核對
==================================================

位置：08 操作紀錄（管理員／主管）
可查操作時間、人員、類型、相關識別及原因，目前顯示最近 200 筆。
入庫紀錄畫面也顯示最近 200 筆。
要查出給誰、在哪個倉庫出、扣哪批，搭配銷售或批次明細查看。

每天結束前核對：
□ 收到的貨是否登在正確倉庫、商品及批次？
□ 實際交出去的貨是否都已確認出庫？
□ 收到的錢是否登到正確訂單與幣別？
□ 客戶欠款是否與收款紀錄一致？
□ 有無重複單據或待主管確認的差異？

==================================================
十二、練習一次：從進貨到收款及調價
==================================================

以下只在已確認隔離的測試網站練習。
使用可辨識的測試商品、客戶與供應商，避免混淆。

情境：北倉收到 A 批 30 支，每支 AUD 40；客戶先買 20 支，
每支賣 AUD 60。

1. 採購入庫：數量 30、成本 40，選北倉。
   結果：庫存 30 支，原始進貨總成本 AUD 1,200。

2. 建立銷售單：數量 20、單價 60。
   結果：應收 AUD 1,200，尚未出貨，庫存仍為 30 支。

3. 確認出庫：選該訂單、北倉，出貨 20 支。
   結果：庫存剩 10 支，出貨成本 20 × 40 = AUD 800。
   毛利 1,200 − 800 = AUD 400。

4. 登錄收款：對這張訂單收 AUD 700。
   結果：已收 700、未收 500，毛利仍是 AUD 400。

5. 調整成本：把 A 批剩餘成本改為 AUD 45，填調整原因。
   結果：剩餘 10 支的庫存成本為 AUD 450。
   第一張訂單成本仍是 AUD 800，毛利仍是 AUD 400。

6. 第二次銷售：另開訂單，5 支、每支 AUD 65，從北倉出貨。
   結果：應收 AUD 325，成本 5 × 45 = AUD 225，毛利 AUD 100。
   北倉剩下 5 支。

最後核對：30 − 20 − 5 = 5 支。
兩次出貨成本不同，但都能追到 A 批及各自出貨紀錄。

==================================================
遇到問題時
